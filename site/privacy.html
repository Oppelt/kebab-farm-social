Privacy Policy

Last updated: November 1, 2026

"Kebab Farm Social" is a private publishing tool used only by the creator of the Roblox game Kebab Farm to post gameplay clips to the creator's own Instagram, YouTube and TikTok accounts. It is not offered to other users.

What data the tool uses

  • Access tokens for the creator's own Instagram, YouTube and TikTok accounts, granted through each platform's official login.
  • Basic account information returned by the platforms (account ID, display name) needed to publish posts.

How the data is stored

Tokens are stored encrypted (AES-256-GCM). The decryption key is kept only on the creator's computer and as an encrypted secret in the creator's GitHub repository. Data is used solely to upload the creator's own videos and is never sold, shared or used for advertising.

Data of other people

The tool does not collect, read or store data about viewers, followers or any other users.

Deleting data

Access can be revoked at any time in the security settings of each platform. Revoking access makes the stored tokens useless; the creator deletes them from the repository on request.

Contact

Questions: please open an issue in the GitHub repository that hosts this site, or contact the Kebab Farm accounts via direct message.
